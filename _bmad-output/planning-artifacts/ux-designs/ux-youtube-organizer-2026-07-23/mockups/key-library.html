Library hub + Tag detail

Re-rendered against the post-validation spines. Library no longer shows a grid of everything — it shows the app's organizational structure as shelf rows, which is how "Library = all videos" and "no chronological feeds" stop contradicting each other. Browsing happens one level down, on Tag detail.

1 · Library — the hub

Rows, not a feed. Nothing to scroll past; every "View more" lands on a finite surface. Sidebar Playlists is now a plain link, so Trash stays visible at any playlist count. Note the 3px edge bar on the active nav item — the surface tint alone measured 1.10:1 and could not carry the signal.
