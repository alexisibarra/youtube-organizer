## Deferred from: code review (second pass) of 1-5-make-backup-target-named-volume-and-verified-restore (2026-08-19)

- **Nothing checks a dump against the database it is being restored into.** `bin/restore-db.sh` proves the archive parses (`pg_restore --list`) and proves the *target* is the library (the container credential cross-check), but never compares the two: a well-formed dump from any other project is accepted into `youtube_organizer`. _Reason for deferring: the meaningful assertion is "this archive's TOC contains the library's tables", which is the same check already deferred for `bin/backup-db.sh` and which cannot be written usefully until Epic 4 lands `Video`/`Tag`/`VideoTombstone`.
