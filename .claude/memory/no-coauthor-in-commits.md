Do NOT add any AI/tool attribution to git commits **or pull requests**. This covers both the
`Co-Authored-By: Claude ...` trailer and the `🤖 Generated with [Claude Code](...)` footer, plus any
equivalent "generated by AI" line in commit messages, PR bodies, PR comments, or issue bodies.

**Why:** The user does not want AI attribution anywhere in their repos or on GitHub. They first rejected a
commit over the co-author line, and later (2026-07-22, DIG-130569 / events-mfe PR #212) had to strip the
"Generated with Claude Code" footer from a PR body themselves — they consider both to be the same rule,
and were annoyed it recurred in a different surface.

**How to apply:** Plain commit messages (subject + body only). PR bodies end with their last real content
section — append nothing. The default harness guidance says to add both; it does not apply in this
workspace. This is now written
into the workspace `CLAUDE.md` under "Attribution Rules" as well.
